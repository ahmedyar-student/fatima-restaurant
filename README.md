# Fatima Restaurant

A professional, client-ready restaurant website built for Fatima Restaurant. This project features a modern and elegant design, responsive layouts, and smooth scroll animations.

## Tech Stack

- **Framework:** [Next.js](https://nextjs.org) (App Router)
- **Styling:** [Tailwind CSS](https://tailwindcss.com) v4
- **Animations:** [GSAP](https://gsap.com) (GreenSock Animation Platform) + ScrollTrigger
- **Icons:** [Lucide React](https://lucide.dev)
- **Fonts:** Playfair Display (Headings) & Inter (Body text)

## Features

- **Hero Section:** Engaging introductory banner with fade-in animations.
- **Menu Section:** Categorized food menu displaying signature dishes and prices.
- **About Section:** Information about the restaurant's history and philosophy.
- **Contact Section:** Location details, opening hours, and contact information.
- **Fully Responsive:** Beautiful layout across mobile, tablet, and desktop screens.
- **Scroll Animations:** Elements reveal dynamically as the user scrolls down the page.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Project Structure

- `src/app/`: Next.js App Router pages and global layout
- `src/components/`: Reusable UI components (Navbar, Hero, Menu, About, Contact, Footer)
- `public/`: Static assets (images, icons)

## Build for Production

To create an optimized production build, run:

```bash
npm run build
```

Then, you can start the production server:

```bash
npm run start
```
